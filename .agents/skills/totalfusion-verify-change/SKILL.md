# Verify change

Read the repository's `AGENTS.md` and the instructions for the area you will change.

It is the maintained workflow shared with Claude Code. Paths and commands in that checklist are relative to the TotalFusion repository root, not this skill folder.

Apply the checklist to the requested task and report the checks you actually ran and any unavailable runtime coverage.
