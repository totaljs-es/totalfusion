Calls a function that sends chunks (a Python generator or a stream function of Rust or Go) with the data of the message. **Every chunk is a message** on the first output, in order; when the stream ends, one message with `{ chunks, cancelled }` goes to the second output, and a failure goes to the third with a `code` and a `message`. The input `Stop` cancels the streams that are running, and so does stopping the flow. The timeout is the longest time without a new chunk.
Runtime Function (module.function) Timeout (ms, 0 = none)
