Calls a function of a WebAssembly module, which runs in a sandbox of TotalFusion with the data of the message and sends the result to the first output. A failure goes to the second output with a `code` and a `message` (the first line of the error, without the traceback: do not connect that output straight to a public response).
Function (module.function) Timeout (ms, 0 = none) Repeat the call on another worker if its worker dies (only for a function that can be repeated with no harm)
